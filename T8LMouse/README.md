# T8L Mouse — управление мышью Mac пультом RadioMaster T8L

Нативная программа для macOS (Apple Silicon M1/M2/M3 и Intel, macOS 12+).

## Что умеет
- Курсор двигается стиком: режим «джойстик» (скорость) или «абсолютный» (стик = точка на экране).
- Прокрутка любой осью или тумблером.
- **Работают все органы управления пульта**: каждая ось, каждая HID-кнопка, крестовина и **каждое положение каждого тумблера** (SA/SB/SC/SD: мин / середина / макс). На любое из них можно назначить действие.
- Действия: левая/правая/средняя кнопка мыши, двойной клик, любая клавиша или сочетание (⌘⇧⌥⌃), прокрутка, громкость/плеер/яркость, точный режим, турбо, включение/выключение управления, курсор в центр, запуск любой команды или программы.
- Режимы: «один раз», «удерживать, пока активно» (например, зажать левую кнопку для перетаскивания), «повторять» (автокликер).
- Калибровка стиков, мёртвая зона, кривая чувствительности, инверсия осей.
- Значок 🎮 в строке меню: быстро включить/выключить управление.
- Настройки сохраняются в `~/Library/Application Support/T8LMouse/config.json`.

## Установка (один раз)
1. Откройте «Терминал».
2. Установите инструменты разработчика Apple (если ещё не стоят):
   ```bash
   xcode-select --install
   ```
3. Перейдите в папку с программой (перетащите папку `T8LMouse` в окно Терминала после `cd `):
   ```bash
   cd ~/Downloads/T8LMouse
   ```
4. Соберите и установите в «Программы»:
   ```bash
   chmod +x build.sh && ./build.sh install
   ```
5. При первом запуске macOS попросит доступ **«Универсальный доступ» (Accessibility)** —
   Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включите **T8LMouse**.
   Без этого программа видит пульт, но не может двигать мышь.

> После каждой пересборки macOS считает программу «новой»: в списке «Универсальный доступ» удалите старую
> запись T8LMouse кнопкой «−» и включите заново.

## Подключение пульта
- Подключите T8L к Mac кабелем USB-C, который **передаёт данные** (не только заряжает).
- Если пульт спрашивает режим USB — выберите джойстик (Joystick / HID / Simulator).
- В окне программы появится «● Подключено: …» и список всех осей и кнопок.

## Настройка
1. Вкладка **«Мышь»** — выберите, какие оси двигают курсор (по умолчанию первые две). Если едет наоборот — «Инвертировать».
2. Вкладка **«Кнопки и тумблеры»** — пошевелите тумблером: его строка подсветится, а зелёная точка покажет текущее положение.
   Нажмите «Назначить…» и выберите действие для каждого положения. Строки можно переименовать (SA, SB, …).
3. Если курсор уплывает сам — вкладка **«Калибровка»**.

### Пример раскладки
| Орган | Положение | Действие |
|---|---|---|
| Правый стик | — | курсор X / Y |
| Левый стик ↔ | — | прокрутка влево/вправо |
| SA | + | Левая кнопка мыши — «удерживать» (перетаскивание) |
| SB | − / + | Левая кнопка мыши (клик) / Правая кнопка мыши (клик) |
| SC | + | Точный режим |
| SD | + | Вкл/выкл управление |

## Если не работает
- **Пульт не виден** — другой кабель/порт; проверьте режим USB на пульте.
- **Значения меняются, а курсор стоит** — нет разрешения «Универсальный доступ» (см. выше).
- **Тумблер не переключает положения** — уменьшите «Порог положений» во вкладке «Мышь» или сделайте калибровку.
